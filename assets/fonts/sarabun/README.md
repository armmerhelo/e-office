# Sarabun

Thai formal-document font, licensed under the SIL Open Font License 1.1.
See `OFL.txt`. This is **Sarabun**, not TH Sarabun New.

Source: https://github.com/google/fonts/tree/88058c714073e72bb1b32baffc2d4ce9bc73944c/ofl/sarabun

Unmodified TTFs: Regular (400), Bold (700), Italic (400), BoldItalic (700).
Studio registers these local files with the browser FontFace API, including in
the shared shell's Shadow DOM, and waits for them before rendering/exporting.

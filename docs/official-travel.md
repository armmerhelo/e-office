# ปฏิทินไปราชการ

เมนู **อื่น ๆ → ปฏิทินไปราชการ** (`index.php?view=official_travel`) ใช้ดูและบันทึกกำหนดการของ ผอ. และรอง ผอ. ไม่ใช่การขออนุมัติเดินทาง และไม่ส่งการแจ้งเตือน

## ก่อนเปิดใช้

1. รัน `php scripts/migrate.php` ในสภาพแวดล้อมของระบบก่อนเผยแพร่หน้าเมนู การรันซ้ำจะไม่ลบรายการเดิม
2. ใช้บัญชี Admin เปิด **จัดการสมาชิกและสิทธิ์ → ตำแหน่ง** เพื่อตรวจว่าบัญชี ผอ. และรอง ผอ. ทุกคนมีตำแหน่งถูกต้อง ฟอร์มจะเลือกได้เฉพาะบัญชีที่กำหนดตำแหน่งแล้ว เมื่อบันทึกรายการ ระบบเก็บชื่อและฝ่ายไว้กับกำหนดการเพื่อให้อ่านประวัติได้แม้เปลี่ยนผู้ดำรงตำแหน่ง
3. ในหน้าสิทธิ์ของสมาชิก ให้มอบ **จัดการปฏิทินไปราชการ** แก่ธุรการหรือเลขานุการที่รับผิดชอบตารางรวม ไม่จำเป็นต้องให้สิทธิ์ Admin
4. ผู้ที่ดูปฏิทินได้คือ Admin ผู้ได้รับสิทธิ์จัดการปฏิทิน รอง ผอ. และ ผอ. เท่านั้น บัญชีอื่นจะไม่เห็นเมนูและเปิดหน้า/API ไม่ได้ เลขที่หนังสือและหมายเหตุภายในดูได้เฉพาะผู้มีสิทธิ์จัดการ/Admin ส่วนรอง ผอ. และ ผอ. ที่ไม่มีสิทธิ์จัดการเห็นเฉพาะข้อมูลประสานงาน เช่น ชื่อ ฝ่าย ภารกิจ สถานที่ และวันเวลา

## การใช้งาน

- บนจอกว้างใช้ปฏิทินรายเดือน บนจอเล็กใช้รายการเรียงตามวันที่ไป กรองตามฝ่ายหรือผู้ไปราชการ กดที่รายการเพื่ออ่านรายละเอียด
- **วันนี้ใครไปราชการ** ใช้วันตามเวลาไทย และแสดงทุกกำหนดการที่มีช่วงวันครอบคลุมวันนี้ ไม่ใช่สถานะเดินทางแบบสด
- กำหนดการหลายวันรวมวันที่ไปและวันที่กลับ หากรู้วันใหม่ให้แก้วันในรายการเดิม หากยังไม่รู้ให้เลือก **เลื่อน / รอวันใหม่** หรือเลือก **ยกเลิก** ตามกรณี ทั้งสองสถานะยังดูย้อนหลังในปฏิทินได้ แต่ไม่ขึ้นในสรุปวันนี้
- หากบันทึกไม่ได้เพราะมีคนแก้รายการเดียวกัน ให้ปิดฟอร์มและเปิดรายการล่าสุด ระบบไม่เขียนทับข้อมูลของอีกคน การเพิ่มและแก้ไขตรวจย้อนหลังได้ใน **ประวัติการใช้งาน** โดยไม่บันทึกภารกิจหรือหมายเหตุลงใน log

ทดสอบด้วย `npm.cmd run test:official-travel` บน MySQL สำหรับทดสอบที่สร้างและลบฐานข้อมูลชั่วคราวได้ ใช้ชื่อ `eoffice_travel_<process-id>_test` ตั้ง `OFFICIAL_TRAVEL_BROWSER=1` เพื่อทดสอบ Chrome จริงและมุมมองมือถือด้วย

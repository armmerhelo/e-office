    1

    เชื่อมต่อ AI

    กำหนด API key และโมเดลสำหรับวิเคราะห์เอกสาร PDF

    Gemini

    ใส่ค่าเฉพาะเมื่อต้องการเปลี่ยน key ระบบจะไม่แสดง key เดิมที่บันทึกไว้

    สร้าง API key ที่ Google AI Studio ↗ (เปิดแท็บใหม่)

    เซิร์ฟเวอร์ยังไม่พร้อมบันทึก API key ผ่านหน้าเว็บ ให้ผู้ดูแลตั้ง EOFFICE_SETTINGS_KEY ก่อน คุณยังแก้ไขโมเดลและหยุดการส่งได้

    รายการจาก Gemini คือโมเดลที่รองรับ generateContent ให้ทดสอบ PDF และ JSON ก่อนใช้จริง รายการนี้ยังไม่ยืนยันความแม่นยำในการอ่านคำสั่งไทย

    ตรวจสอบการเชื่อมต่อ

    ทดสอบ key และโมเดลด้วย PDF ตัวอย่าง ใช้ค่าที่กรอกอยู่โดยยังไม่บันทึก

    ต้องมี API key ก่อนโหลดโมเดลหรือทดสอบ AI

    ยังไม่ได้ทดสอบค่าชุดนี้

    2

    SMTP และผู้ส่ง

    ค่าชุดนี้ใช้กับอีเมลคำสั่ง การทดสอบใช้ค่าที่กรอกโดยยังไม่บันทึก · ข้ามได้หากวิเคราะห์อย่างเดียว

    ทดสอบ SMTP

    ส่งอีเมลจริงถึงที่อยู่ข้างต้นเท่านั้น ผลผ่านหมายถึง SMTP รับเมล ยังไม่ยืนยันการเข้า Inbox ผลทดสอบใช้ยืนยันเปิดส่งได้ 24 ชั่วโมง

    3

    ทดลองอ่านคำสั่งจริง

    ส่ง PDF และรายชื่อบุคลากรให้ Gemini เพื่อทดลองจับคู่ ไม่สร้างคิวและไม่ส่งอีเมล · ไม่บังคับ

    รายชื่อที่ไม่มั่นใจจะไม่จับคู่ ผลที่แสดงเป็นข้อเสนอจาก AI ให้ตรวจสอบกับเอกสารต้นฉบับ ไฟล์ทดลองไม่ถูกบันทึกเป็นเอกสารในระบบ

      ประมาณการค่าใช้จ่าย AI

      กรอกราคา USD ต่อ 1 ล้าน token ตามโมเดล/แพ็กเกจของคุณ ไม่ใช่ยอดเรียกเก็บจริง ใช้อัตรานี้ประมาณย้อนหลัง 30 วันทุกโมเดล

      4

      เลือกโหมดทำงาน

      ตรวจความพร้อมและผลกระทบก่อนบันทึก

      กำลังโหลดสถานะ…

      มีผลเมื่อกด “บันทึกการตั้งค่า” เท่านั้น โหมดส่งต้องตั้ง SMTP และส่งทดสอบผ่านภายใน 24 ชั่วโมง ก่อนเปิดจากสถานะหยุดต้องพบ Cron ภายใน 15 นาที

      เปิดครั้งแรก เฉพาะคำสั่งใหม่หลังเปิดใช้จะเข้าคิวอัตโนมัติ คำสั่งเก่าต้องนำเข้าคิวเอง

      หยุดชั่วคราว หยุดวิเคราะห์และส่ง เก็บงานค้างและนโยบายเดิมไว้ เมื่อเลือกเปิดอีกครั้งระบบจะทำงานตามโหมดที่เลือก

      เปลี่ยนเป็นส่งอัตโนมัติ งานที่พักตามนโยบายจะกลับเข้าคิว งานที่พร้อมอาจส่งในรอบ Cron ถัดไป

      เปิดใช้งานครั้งแรก —

      แม่แบบอีเมล · หัวเรื่อง ข้อความ และลายเซ็น

      ตัวแปร: {doc_number}, {doc_name}, {doc_year}, {recipient_name} · ข้อความแสดงเป็นข้อความธรรมดา ระบบเติมลิงก์ PDF ให้

      หยุดใช้ API Key ปัจจุบัน

      หากต้องการเปลี่ยน Key ให้เพิ่มตัวใหม่ในคลัง ทดสอบ และเลือกใช้งาน

      กำลังโหลดการตั้งค่า…

      การทดสอบ AI ไม่ได้บันทึกค่าลงระบบ

      คลัง API Key · จัดการแยกจากการตั้งค่าหลัก

      แต่ละปุ่มบันทึกเฉพาะคลังทันที ใช้โมเดลที่บันทึกไว้ แบบร่างการตั้งค่าหลักยังอยู่ · การเลือก Key หลักมีผลต่อคำขอ AI ถัดไป

      เพิ่ม Key สำรอง / เตรียมหมุนเวียน

      รหัสอ้างอิงเป็นรหัสสุ่ม ไม่ใช่ส่วนหนึ่งของ Key · ไม่มีการสลับ Key อัตโนมัติเมื่อโควตาเต็ม

      การพักใช้/ลบมีผลเฉพาะ E-Office หากต้องการเพิกถอน Key จริง ให้ดำเนินการใน Google AI Studio การลบล้างข้อมูลลับออกจากคลังและคงประวัติการใช้งานไว้

      สำรองและเปลี่ยนกุญแจเข้ารหัส

      สำรองฐานข้อมูลและ EOFFICE_SETTINGS_KEY แยกในพื้นที่ private ก่อนเปลี่ยน หยุด web/worker ชั่วคราว แล้วใช้คำสั่ง CLI php scripts/rotate-order-settings-key.php ตาม ORDER_EMAILS.md คำสั่งจะเข้ารหัสคลัง Key และ SMTP ใหม่แบบ transaction หากกุญแจเดิมสูญหายจะถอดรหัสไม่ได้ ต้องใส่ข้อมูลลับใหม่

      การตั้งค่าที่บันทึกไว้

      การใช้งาน AI · 30 วัน

      นับคำขอสำเร็จที่ระบบบันทึกหลังอัปเกรด รวมการทดสอบ ไม่ใช่โควตาคงเหลือจาก Google

      ประวัติล่าสุด

      เริ่มใช้งานใน 4 ขั้นตอน

      1. เชื่อมต่อและทดสอบ AI

        กำหนด Key/โมเดล ทดสอบการอ่าน PDF

      2. ตั้งค่าและส่งทดสอบ SMTP

        ตรวจกล่องจดหมายและสแปม ข้ามได้หากวิเคราะห์อย่างเดียว

      3. ทดลอง PDF จริง

        ตรวจความถูกต้องของรายชื่อก่อนใช้งาน ไม่บังคับ

      4. เลือกโหมดและบันทึก

        ตรวจ Cron และผลกระทบต่องานค้างก่อนเปิดระบบ

      การทดสอบ AI/PDF ไม่ส่งอีเมล ส่วนปุ่มส่งอีเมลทดสอบส่งจริงเฉพาะปลายทางที่กรอก

      ระบบทำงานอย่างไร

      อ่าน PDF ทุกไฟล์↓รวมรายชื่อผู้รับ↓ส่งอีเมลผ่าน SMTP

      Gemini ใช้วิเคราะห์เอกสาร ส่วนเซิร์ฟเวอร์เป็นผู้ส่งอีเมลตามรอบ Cron

      คู่มือสำหรับผู้ดูแลเซิร์ฟเวอร์

      ตั้ง Cron ทุก 5 นาที ใช้ launcher ตาม ORDER_EMAILS.md บนโฮสติ้ง

      /bin/sh /absolute/path/to/site/scripts/order-cron.sh

      หรือใช้ PHP CLI ที่มี extension ครบ เรียก php scripts/order-emails.php โดยใช้ค่าตั้งค่าเดียวกับเว็บไซต์ ตรวจ log ในพื้นที่ private

      การบันทึกข้อมูลลับผ่านหน้าเว็บต้องตั้ง EOFFICE_SETTINGS_KEY ดูขั้นตอนใน ORDER_EMAILS.md

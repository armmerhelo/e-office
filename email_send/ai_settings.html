1

เชื่อมต่อ AI

กำหนด API key และโมเดลสำหรับวิเคราะห์เอกสาร PDF

Gemini

ใส่ค่าเฉพาะเมื่อต้องการเปลี่ยน key ระบบจะไม่แสดง key เดิมที่บันทึกไว้

เซิร์ฟเวอร์ยังไม่พร้อมบันทึก API key ผ่านหน้าเว็บ ให้ผู้ดูแลตั้ง EOFFICE_SETTINGS_KEY ก่อน คุณยังแก้ไขโมเดลและหยุดการส่งได้

พิมพ์ชื่อโมเดล หรือโหลดรายการจาก Gemini แล้วเลือกด้านล่าง

ตรวจสอบการเชื่อมต่อ

ทดสอบ key และโมเดลด้วย PDF ตัวอย่าง ใช้ค่าที่กรอกอยู่โดยยังไม่บันทึก

ยังไม่ได้ทดสอบค่าชุดนี้

2

การส่งอีเมลอัตโนมัติ

ระบบส่งอีเมลผ่าน SMTP ที่ตั้งไว้บนเซิร์ฟเวอร์

การเปลี่ยนสวิตช์มีผลเมื่อกด “บันทึกการตั้งค่า” เท่านั้น

เปิดครั้งแรก เฉพาะคำสั่งใหม่หลังเปิดใช้จะเข้าคิวอัตโนมัติ คำสั่งเก่าต้องนำเข้าคิวเอง

หยุดชั่วคราว เก็บงานค้างไว้ เมื่อเปิดอีกครั้งระบบจะทำงานต่อ

เปิดใช้งานครั้งแรก —

จัดการ API key เพิ่มเติม

หากต้องการเปลี่ยน key ให้กรอก key ใหม่ในส่วนเชื่อมต่อ AI โดยไม่ต้องล้างก่อน

กำลังโหลดการตั้งค่า…

การทดสอบ AI ไม่ได้บันทึกค่าลงระบบ

เริ่มใช้งานใน 3 ขั้นตอน

  1. กำหนด key และโมเดล

    ใช้ key ปัจจุบัน หรือใส่ key ใหม่

  2. ทดสอบการเชื่อมต่อ AI

    ตรวจว่าโมเดลอ่าน PDF และคืนผลได้

  3. เปิดส่งและบันทึก

    คำสั่งจะถูกประมวลผลในรอบทำงานถัดไป

การทดสอบใช้เอกสารตัวอย่าง ไม่ส่งคำสั่งจริงและไม่ส่งอีเมลถึงบุคลากร

ระบบทำงานอย่างไร

อ่าน PDF ทุกไฟล์↓รวมรายชื่อผู้รับ↓ส่งอีเมลผ่าน SMTP

Gemini ใช้วิเคราะห์เอกสาร ส่วนเซิร์ฟเวอร์เป็นผู้ส่งอีเมลตามรอบ Cron

คู่มือสำหรับผู้ดูแลเซิร์ฟเวอร์

ตั้ง Cron ให้เรียกคำสั่งนี้ทุก 5 นาที ด้วย PHP CLI และค่าตั้งค่าเดียวกับเว็บไซต์

php scripts/order-emails.php

หากไม่พบรอบทำงานล่าสุด ให้ตรวจ Cron และบันทึกการทำงานบนเซิร์ฟเวอร์

การบันทึก key ผ่านหน้าเว็บต้องตั้ง EOFFICE_SETTINGS_KEY ก่อน ดูขั้นตอนใน ORDER_EMAILS.md

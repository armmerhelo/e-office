จัดการสมาชิกและสิทธิ์

กำหนดสิทธิ์รายบุคคล สมาชิกหนึ่งคนดูแลงานได้หลายอย่าง

Auto send — เลขาฝ่าย / รองฝ่าย

เมื่อเลขาฝ่ายประทับตรา ยืนยันลงทะเบียนรับเอกสาร และบันทึกสำเร็จ ระบบจะเพิ่มรองฝ่ายเป็นผู้รับและแจ้งเตือนอัตโนมัติ พร้อมบันทึกประวัติการรับ

ฝ่าย / ตราประทับเลขาฝ่าย (ผู้ประทับตรา)รองฝ่าย (ผู้รับอัตโนมัติ)จัดการ

ยังไม่มี Auto send กดเพิ่มคู่เลขา / รองฝ่ายเพื่อเริ่มตั้งค่า

คู่เดิมใช้ “ทุกฝ่าย (คู่เดิม)” ให้เลือกฝ่ายให้ตรงกับตราประทับเพื่อส่งเฉพาะฝ่ายนั้น การลบคู่จะหยุด Auto send หลังบันทึก และไม่ถอนผู้รับจากเอกสารที่ส่งไปแล้ว

ลำดับชื่อ – สกุล / อีเมลระดับผู้ใช้สิทธิ์เพิ่มเติมจัดการ
กำลังตรวจสอบสิทธิ์และโหลดข้อมูล...

บุคลากรทั่วไปมีสิทธิ์พื้นฐานในการใช้งานระบบ การเพิ่ม–ถอนสิทธิ์และการเปลี่ยนระดับผู้ใช้ทำได้โดย Admin สูงสุดเท่านั้น

เพิ่มสมาชิก

หลังสร้างสมาชิก เปลี่ยนระดับจากปุ่ม “ระดับ” และเลือกสิทธิ์ดูแลงานจากปุ่ม “สิทธิ์”

อย่างน้อย 8 ตัวอักษร / เว้นว่างหากไม่เปลี่ยน

กลุ่มงานที่ได้รับมอบหมาย

กำลังโหลดข้อมูลกลุ่มงาน กรุณารอสักครู่...

    สิทธิ์การใช้งาน

    เลือกได้หลายสิทธิ์ หรือถอนทุกสิทธิ์เพื่อให้เหลือเฉพาะการใช้งานพื้นฐาน

    การเปลี่ยนแปลงมีผลกับคำขอถัดไป โดยสมาชิกไม่ต้องออกจากระบบ

    เปลี่ยนระดับผู้ใช้

    การเปลี่ยนระดับแยกจากการแก้ข้อมูลทั่วไป และต้องเหลือ Admin สูงสุดอย่างน้อยหนึ่งคน
